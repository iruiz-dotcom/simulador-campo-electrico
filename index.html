📖 Guía de Evaluación e Interacción

Fundamento Teórico del Modelo

En el espacio electrostático generado por $N$ cargas discretas $q_i$, el campo es conservativo y deriva de un potencial escalar:

V(\mathbf{r}) = k_e \sum_{i=1}^{N} \frac{q_i}{|\mathbf{r} - \mathbf{r}_i|}
\mathbf{E}(\mathbf{r}) = -\nabla V = k_e \sum_{i=1}^{N} \frac{q_i(\mathbf{r} - \mathbf{r}_i)}{|\mathbf{r} - \mathbf{r}_i|^3}
Actividad 1

El Dipolo Eléctrico y Ortogonalidad

Coloca una carga de $+2\text{ nC}$ y una de $-2\text{ nC}$ separadas horizontalmente. Observa la dirección con la que las líneas de campo cortan las líneas equipotenciales en todos sus puntos de intersección.

Pregunta de Evaluación 1: ¿Qué ángulo forman las líneas de campo eléctrico con respecto a las líneas equipotenciales en cualquier punto del espacio?
a) $0^\circ$ (Paralelas entre sí)
b) $45^\circ$
c) $90^\circ$ (Perpendiculares)
d) Varía según la distancia a la carga.
Actividad 2

Geometría del Potencial Cero ($V = 0\text{ V}$)

Manteniendo el dipolo anterior ($+2\text{ nC}$ y $-2\text{ nC}$), ubica la línea equipotencial de $V = 0\text{ V}$ (color verde destacado). Ahora aumenta la carga positiva a $+6\text{ nC}$ con la barra deslizadora.

Pregunta de Evaluación 2: ¿Qué le sucede a la línea o curva equipotencial de $V = 0\text{ V}$ cuando las magnitudes de las cargas dejan de ser iguales?
a) Permanece como una línea recta en el punto medio.
b) Se curva envolviendo a la carga de menor magnitud absoluta.
c) Desaparece completamente del plano.
d) Se convierte en una elipse alrededor de la carga positiva.
Actividad 3

Trabajo y Movimiento de Cargas

Utiliza la sonda/sensor para registrar el potencial eléctrico en dos puntos situados sobre la misma línea equipotencial. Usa la calculadora de trabajo integrada en la barra lateral.

Pregunta de Evaluación 3: ¿Cuánto trabajo realiza el campo eléctrico al trasladar una carga de prueba $q_0$ a lo largo de una misma línea equipotencial?
a) $W = 0\text{ Joules}$, ya que $\Delta V = V_B - V_A = 0$ y $W = -q_0 \Delta V$.
b) Depende de la trayectoria seguida entre ambos puntos.
c) Es siempre positivo y proporcional a la distancia recorrida.
d) $W = q_0 |\mathbf{E}| d$, independiente de la curvatura.

🚀 Despliegue Público en GitHub Pages

Este simulador está completamente contenido en un único archivo index.html (HTML5 + CSS3 + JS nativo ES6), sin dependencias complejas de servidor. Puedes publicarlo en la nube en menos de 2 minutos de forma 100% gratuita.

Paso 1: Crear el Repositorio

Ingresa a tu cuenta de GitHub y crea un nuevo repositorio público (ej. simulador-campo-electrico).

Paso 2: Subir el Archivo

Sube el archivo index.html directamente a la raíz (rama main) del repositorio:

git init git add index.html git commit -m "Publicar simulador de campo eléctrico" git branch -M main git remote add origin https://github.com/iruiz-dotcom/simulador-campo-electrico.git git push -u origin main
Paso 3: Activar GitHub Pages

En GitHub ve a Settings > Pages. En "Build and deployment", selecciona como fuente la rama main y la carpeta / (root). Haz clic en Save.

Paso 4: URL de Acceso Universal

En pocos segundos, GitHub generará tu enlace permanente para compartir con los estudiantes:
